# Shining Scanner Reviews
The goal of this repository is to provide my reviews of Shining 3D's scanners. This repo is a work in progress.

## Issues
This is used to document bugs and feature suggestions. I will post all my issues and suggestions here.

I hope that Shining will use this as an example to improve their support system for issues such as bugs and enhancements. Tickets and forums still have a place, but a system like [Issues](https://github.com/JeremiahGillis/shining-3d-scanners/issues) in GitHub provides the following benefits:
-	Each issue is very concise and can follow a template. The template will guide the user on what information is required. This saves time instead of going back and forth multiple times in a ticket.
-	It is public facing:
    - Allow users to find their issue if it was submitted by someone else. If so, they can add additional details, or just a reaction to say they have the same issue. This saves time for the user. It also saves time for developers since all relevant information is contained in one issue, as opposed to many tickets reporting the same issue.
    - Users can suggest or comment on enhancements which help developers determine what should be implemented.
    - Shows prospective customers that you address issues in a timely manner.
- Developers can comment on each issue, such as:
    - We have replicated the issue or need additional details to replicate.
    - Timeline to fix the issue or implement the new feature.
    - What software version contains the fix, instead of looking at release notes that state `Fix some bugs`, which may not contain the fix.
    - The user feels more important since there is no intermediary forwarding information to and from R&D.
